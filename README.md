# Kelly's AIRLIFT — Player Donate UI

An optional client addon for players joining the **Aryx Shipyard Nuclear Option server**.

It adds **RAPID Combat Drop** to `Donate > Vehicles`, allowing you to purchase a five-Chimera runway assault against an enemy-held airport.

## Download

### [Download the latest Player Donate UI](https://github.com/Kelly-D-Ripper/Kelly-s-AIRLIFT/releases/latest)

Only download the file ending in:

`PUBLIC-UI-NO034.zip`

## Install

1. Extract the ZIP into your Nuclear Option installation folder.
2. Confirm this file exists:
   `BepInEx/plugins/KellysAIRLIFTPublicUI/KellysAIRLIFTPublicUI.dll`
3. Restart Nuclear Option and join Aryx Shipyard.

## Use

1. Open the **Donate** menu.
2. Select **Vehicles > RAPID Combat Drop**.
3. Choose an enemy-held airport and confirm the purchase.

**RAPID** means **Runway Assault Package Insertion & Deployment**.

The addon only provides the player menu. The Aryx Shipyard server controls the price, cooldown, validation, aircraft spawning and cargo deployment. It cannot spawn anything or bypass server rules by itself.
