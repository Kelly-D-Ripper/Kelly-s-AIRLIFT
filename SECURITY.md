# Security policy

Report command-authorization, allocation, server-authority or unsafe network
spawn issues privately to the repository owner before opening a public issue.

AIRLIFT trusts no client-supplied price, faction, ownership, runway or cooldown
value. Reports should include the AIRLIFT version, Nuclear Option version,
server/listen-server mode and the smallest relevant BepInEx log excerpt. Never
include Steam authentication tokens, server passwords or unrelated player data.
