# Kelly's AIRLIFT 0.13.1

Combat drops now always spawn beyond the running map boundary plus the
configured `OffMapSpawnMargin`. This applies to public purchases, owner
commands, dedicated servers and listen servers. The close `SpawnDistance`
entry remains available only for normal AA local testing.

The five combat Chimeras retain the 0.13.0 AGM-68 runway-suppression loadout.
Hostile ground units and hostile aircraft taxiing or taking off below the 35 m
runway ceiling may be engaged without the transports leaving their ingress
route.

## Release files

- `KellysAIRLIFT-0.13.1-SERVER-NO034.zip` - clean dedicated-server install.
- `KellysAIRLIFT-0.13.1-PUBLIC-UI-NO034.zip` - optional player Donate-menu UI.
- `KellysAIRLIFT-0.13.1-LOCAL-TEST-NO034.zip` - listen-server test package.
- `KellysAIRLIFT-0.13.1-NO034.zip` - upgrade-safe general package.
- `KellysAIRLIFT-0.13.1-SOURCE.zip` - source-only GitHub archive.

The Aryx MC-260 Chimera addon, Nuclear Option assemblies and BepInEx binaries
are prerequisites and are not redistributed.
