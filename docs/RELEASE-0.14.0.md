# Kelly's AIRLIFT 0.14.0 — RAPID

**RAPID** means **Runway Assault Package Insertion & Deployment**. It is the
public name for AIRLIFT's five-Chimera combat runway package.

Players can choose an enemy-held airport from the optional Donate-menu client
addon and purchase a server-authoritative RAPID drop. The canonical request is
`/airlift purchase rapid <enemy-airport>`. Authorized owners can use
`/airlift rapid <BDF|PALA> <airbase> <runway-number|random>`. Existing scripts
using `combat` continue to work as compatibility aliases.

RAPID retains the complete runway-assault feature set delivered through the
0.13 series: off-map ingress, five ground-level cargo aircraft, AGM-68 runway
suppression, compact-runway support for strips such as Dustbowl, independent
survivor handling, cargo-safe extraction and native vehicle dispersal after
touchdown. The normal four-Chimera AA-battery operation is unchanged.
